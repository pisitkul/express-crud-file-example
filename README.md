# Express CRUD API with Swagger (TypeScript)

This project is a simple example API built with Express.js and TypeScript for managing user data, with integrated Swagger UI for API documentation and testing.

โปรเจกต์นี้เป็นตัวอย่าง API อย่างง่ายที่พัฒนาด้วย Express.js และ TypeScript สำหรับจัดการข้อมูลผู้ใช้ พร้อมทั้งรวม Swagger UI สำหรับเอกสารและทดสอบ API

## 🚀 Features

- CRUD (Create, Read, Update, Delete) operations for users  
  รองรับการทำงาน CRUD (สร้าง, อ่าน, แก้ไข, ลบ) สำหรับผู้ใช้  
- In-memory data storage using `users.ts`  
  ใช้ `users.ts` เป็นแหล่งเก็บข้อมูลในหน่วยความจำ (ไม่ถาวร)  
- Swagger UI for API documentation and testing  
  มี Swagger UI สำหรับดูเอกสารและทดลองเรียกใช้งาน API  
- Written in TypeScript for better type safety  
  เขียนด้วย TypeScript เพื่อเพิ่มความปลอดภัยและความถูกต้องของโค้ด  

## 🧰 Tech Stack

- Node.js  
- Express.js  
- TypeScript  
- Swagger (OpenAPI)
